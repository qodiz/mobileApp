# ClearCalls — офлайн-детектор слова «ФСБ»

Android-приложение на Kotlin/Compose, которое полностью локально (без сети) слушает
микрофон через [Vosk](https://alphacephei.com/vosk/) и показывает уведомление при
обнаружении ключевого слова «ФСБ» с учётом вариантов произношения/распознавания.

## Структура проекта

```
app/src/main/java/com/example/kwspotter/
  MainActivity.kt        — Compose UI, разрешения, запуск/остановка сервиса
  ListenerService.kt      — Foreground Service, обёртка над Vosk SpeechService
  KeywordMatcher.kt       — нормализация текста + fuzzy-сравнение (Левенштейн)
  NotificationHelper.kt   — каналы уведомлений, heads-up алерт, вибрация
  ModelManager.kt         — распаковка офлайн-модели Vosk из assets в filesDir
  ui/theme/Theme.kt       — тема Material3
app/src/main/assets/vosk-model-small-ru-0.22/ — офлайн-модель, встроенная в APK
app/src/main/AndroidManifest.xml
app/build.gradle.kts
```

## Офлайн-модель Vosk

Приложение использует `vosk-model-small-ru-0.22` (~45 МБ, официальная модель проекта
[Vosk](https://alphacephei.com/vosk/models/vosk-model-small-ru-0.22.zip), alphacephei.com).

Модель **встроена прямо в APK**: она лежит в `app/src/main/assets/vosk-model-small-ru-0.22/`
и попадает в сборку приложения автоматически при компиляции. Никакого скачивания при
старте приложения не происходит — пользователю ничего не нужно докачивать.

При первом нажатии кнопки «Начать прослушивание» `ModelManager.ensureModel(...)`
копирует модель из assets в приватную папку приложения
(`context.filesDir/vosk-model-small-ru-0.22`), так как нативный код Vosk/Kaldi должен
работать с обычными файлами на диске, а не с записями внутри APK. Эта копия происходит
локально, без сети, и только один раз — при повторных запусках `isModelReady(...)`
обнаруживает уже распакованную модель и копирование пропускается. Разрешение
`INTERNET` приложению больше не требуется и не объявлено в манифесте.

Из-за встроенной модели размер APK/AAB увеличивается минимум на ~45 МБ.

Если вы захотите обновить модель (например, на более новую версию), просто замените
содержимое `app/src/main/assets/vosk-model-small-ru-0.22/` файлами из архива с сайта
Vosk (или положите новую модель под другим именем и обновите константы
`ASSET_MODEL_PATH`/`MODEL_DIR_NAME` в `ModelManager.kt`).

## Как собрать

Рекомендуемый способ — открыть проект в **Android Studio** (Koala/Ladybug и новее):
1. `File → Open` → выбрать папку `mobileApp`.
2. Android Studio предложит создать Gradle Wrapper — согласитесь (в репозитории
   есть только `gradle/wrapper/gradle-wrapper.properties`, сам `gradlew`/`gradlew.bat`
   и wrapper-jar не сгенерированы, так как это бинарный файл).
3. Дождитесь Gradle sync — подтянутся зависимости `vosk-android`, Compose BOM и т.д.
4. Запустите на устройстве/эмуляторе с микрофоном (в эмуляторе распознавание речи
   не проверить без прокинутого аудио).

Альтернатива из терминала, если у вас установлен Gradle:
```
gradle wrapper --gradle-version 8.7
./gradlew assembleDebug
```

## Логика распознавания

- `ListenerService` поднимает Foreground Service (`FOREGROUND_SERVICE_MICROPHONE`),
  грузит `org.vosk.Model` из распакованной папки и создаёт `Recognizer` с
  **ограниченной грамматикой** — JSON-список допустимых фраз (варианты слова +
  `[unk]` как "мусорная" категория для остальной речи). Это снижает нагрузку на CPU
  и повышает точность по сравнению с полным словарём.
- Каждая партиальная/финальная гипотеза от Vosk прогоняется через
  `KeywordMatcher.containsKeyword()`:
  - нормализация (нижний регистр, только кириллица и пробелы);
  - "скользящее окно" из 1–3 соседних слов склеивается в одну строку
    (покрывает случаи вида «эф эс бэ», распознанные как отдельные слова);
  - сравнение с эталонными вариантами (`фсб`, `эфэсбэ`, `эфсб`, `ефсб`, `эфэсб`,
    `фэсбэ`, `эфесбе`, `афсб`) через расстояние Левенштейна с допуском 1–2 символа.
- При совпадении — `NotificationHelper.showKeywordDetected()`: heads-up уведомление
  с высоким приоритетом + короткая вибрация. Задержка — в пределах 1–2 сек, так как
  срабатывание идёт уже на partial-гипотезах, не дожидаясь финального результата.

## Разрешения

`RECORD_AUDIO`, `POST_NOTIFICATIONS` (Android 13+) запрашиваются в UI по нажатию
кнопки, если ещё не выданы. `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_MICROPHONE`
объявлены в манифесте (обычные, не runtime-разрешения). Сетевые разрешения приложению
не нужны — модель встроена в APK и никогда не скачивается.

## Известные ограничения MVP

- Нет экрана настроек (порог чувствительности, история срабатываний) — по ТЗ
  требуется только один экран с одной кнопкой.
- `gradlew`/`gradlew.bat`/wrapper-jar не включены (бинарный файл) — Android Studio
  сгенерирует их автоматически при открытии проекта.
